# Security policy

There is no published preview yet. Once previews are available, report issues against the latest published preview, or include the full Git commit if you built from source.

## Reporting a vulnerability

Open [Security Advisories](https://github.com/Colnnn/OpenBreak/security/advisories) and choose **Report a vulnerability** if that option is available. In the private report, include the affected version or commit, Windows version, impact, and steps to reproduce using sample data.

If the private reporting option is unavailable, open a [GitHub issue](https://github.com/Colnnn/OpenBreak/issues/new) asking a maintainer for a private contact method. Use a generic title such as “Request for private security contact” and keep vulnerability details, reproduction steps, logs, and attachments out of the issue.
